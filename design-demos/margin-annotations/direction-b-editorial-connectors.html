Why this program

What would show that a model has learned a linguistic distinction, rather than a shortcut that happens to produce the same answer? Successful behaviour may rely on the wrong feature, and an internal correlate matters only if it helps explain a controlled behavioural effect.

AMotive

A model can arrive at the right answer for the wrong reason. The longer-term aim is to understand what lets structured meaning, rather than shortcuts, guide behaviour in new contexts.

01Correct behaviour is not enough

Cross-lingual ProtoBias

Holding each image pair fixed while varying the prompt language showed me why a correct judgment is not yet evidence of semantic sensitivity: a model may instead rely on a culturally familiar prototype. The project established the first constraint on my current work — separate the target linguistic relation from cheaper cues that can mimic it.

First-author paper · approximately 12,600 judgments · seven languages

02Internal correlation is not enough

Latent Control States

This collaboration moved the question from behavioural sensitivity to causal relevance. If framing changes an answer, does it also change an internal state responsible for that answer? The project established the second constraint I now carry forward: internal structure matters only relative to a precisely defined behavioural contrast.

Research program

From linguistic analysis to evidence

The broader program connects formal semantics with two empirical questions. How does a linguistic function emerge in human cognition? Can it be learned from linguistic input alone? The same semantic analysis formulates both questions, without treating models as stand-ins for people.

CBoundary
