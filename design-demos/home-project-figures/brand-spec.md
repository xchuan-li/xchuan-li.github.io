# Xiaochuan Li academic site — extracted design context

## Source

The design context is extracted from the current local Astro codebase and the live site. This is an existing personal academic identity, not a new commercial brand.

## Core palette

- Page background: `#f8f9fa`
- Surface: `#ffffff`
- Secondary surface: `#eef1f4`
- Primary text: `#1b1e24`
- Muted text: `#5f6672`
- Dim text: `#98a0ac`
- Hairline border: `rgba(23, 33, 48, 0.11)`
- Strong border: `rgba(23, 33, 48, 0.20)`
- Primary accent: `#3d5a73`
- Supporting semantic accents already present in the site: teal `#1d9e75`, coral `#d85a30`, amber `#ba7517`, indigo `#46567a`. These are permitted only where they encode a genuine distinction.

## Typography

- Primary sans-serif: Inter with system sans-serif fallback.
- Display: currently the same restrained sans-serif family.
- Metadata and diagram labels: JetBrains Mono / system monospace.
- Serif is available for editorial captions or conceptual emphasis, but must not replace the site’s overall sans-serif voice.

## Existing assets

- Portrait: `public/images/headshot.jpg`; not required in these Selected Work prototypes.
- Institution marks: `public/images/logos/*.svg`; not relevant to project diagrams.
- Existing figure grammar: `.essay-fig` in `src/styles/global.css`, plus `HeroWorlds.astro` and several dormant diagram components.

## Non-negotiable constraints

- Preserve the homepage’s quiet academic credibility.
- Figures must explain real structures and must not be ornamental glyphs.
- No fabricated results or visually definitive claims for work still under review or in design.
- Use dashed edges, open nodes, and explicit status labels for hypotheses and candidate designs.
- Keep all project titles and current status language accurate.
- Use one coherent line-and-node family across projects, with enough variation that the four questions remain distinguishable.
